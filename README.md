一个基于 HTML/CSS/JavaScript 的单页工具，用于快速生成高对比度的情绪化封面（支持小红书与公众号），并可自由拖动元素与上传图片进行排版。

## 文件与运行

- 入口文件：`小红书情绪抓手封面设计.html`
- 运行方式：下载后双击用浏览器打开即可，无需安装
- 在线依赖：Tailwind CSS CDN、Google Fonts、`html2canvas` CDN（需联网）

## 功能概览

- 平台比例切换：小红书 3:4、公众号 2.35:1
- 配色方案：三套高对比渐变主题（白/橙/蓝）
- 文案编辑：主标题、副标题即时预览
- 视觉锚点：下划线、高亮色块、圆形焦点可切换
- 文本对齐：居中或左上对齐
- 元素拖拽：主标题、副标题、视觉锚点均可自由拖动
- 图片上传：本地图片添加到封面并可拖动
- 一键导出：生成当前封面区域内的 PNG 图片

## 使用步骤

1. 打开 `小红书情绪抓手封面设计.html`
2. 选择平台与配色方案，或选择内容模板
3. 编辑主标题与副标题；选择视觉锚点与对齐方式
4. 上传图片并点击“添加到封面”，拖动到合适位置
5. 用鼠标拖动主标题、副标题、强调线/色块/圆形到理想排版
6. 点击“导出为PNG图片”生成成品

## 技术说明

- 依赖：`html2canvas` 用于将封面区域渲染为图片；TailwindCSS 用于快速样式；Google Fonts 提供字体
- 拖拽实现：针对可拖元素绑定指针事件，记录位移并叠加到 `transform: translate(x,y)`，支持重复更新与不同初始样式
