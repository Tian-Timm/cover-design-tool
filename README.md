这是一个基于 HTML/CSS/JavaScript 的单页工具，用于快速生成高对比度、情绪化的社交媒体封面设计。

## 🚀 快速使用

1.  **直接访问：**
    -   你可以将 `index.html` 文件下载到本地，直接用浏览器打开即可使用。
    -   （如果你开启了 GitHub Pages，可以提供在线预览链接）
2.  **操作步骤：**
    -   选择平台（小红书/公众号）。
    -   选择配色方案。
    -   输入主标题和情绪钩子（副标题）。
    -   点击“导出为PNG图片”。

## ✨ 主要功能

* 支持小红书 (3:4) 和公众号 (2.35:1) 比例切换。
* 三种预设配色方案。
* 支持自定义主副标题。
* 支持视觉锚点（下划线、色块、圆形）样式。

## ⚠️ 注意事项

本工具依赖于 `html2canvas` 库进行图片导出，请确保在联网环境下运行。
